# AI Agents Portfolio

A set of three small AI agents built to explore different core patterns in LLM tool-use — web search, retrieval-augmented generation, and code execution — all running on free-tier APIs. Built as part of my prep for a Data Science/AI master's application, to go beyond standard coursework projects and show hands-on agent-building skills.

## The Agents

- [Research / Study Assistant Agent](https://github.com/ijlalXhaider/Research-Agent) — takes a question, decides on its own whether it needs to search the web, and returns a synthesized, cited answer.
- [RAG Q&A Agent](https://github.com/ijlalXhaider/RAG-QA-AGENT) — answers questions grounded in your own documents using embeddings and a local vector database.
- [Data Analysis Agent](https://github.com/ijlalXhaider/data-analysis-agent) — ask questions about a CSV in plain English; it writes and runs real pandas code to answer.

All three use the same core "model decides when to call a tool" pattern in slightly different shapes, and all run at $0 cost using free-tier APIs.
